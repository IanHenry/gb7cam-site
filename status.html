Partner Map

Every AXUDP peer GB7CAM is configured to reach, not only the ones answering at this moment. That distinction matters: the node carries far more configured peers than are up at any instant, and a map of only the live ones would flatter the network.

Colour is how long each link has been up without a break, so a peer added last week is not marked down for being new. Grey with a dashed line means configured but not linked right now, and the table below the map gives the last time each of those was seen. Positions are supplied by the operators; where none is known the station is drawn hollow at the centre of its country rather than guessed at.
